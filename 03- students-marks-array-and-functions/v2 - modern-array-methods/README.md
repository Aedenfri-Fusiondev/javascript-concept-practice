# Student Mark Filter, Average & Report Generator
## Modern JavaScript Refactor

This is the refactored version of the original 
student mark project — rewritten using modern 
JavaScript methods: reduce, sort, map, 
spread operator and ternary operators.

## What Changed from V1

| Feature | V1 | Modern Version |
|---|---|---|
| Average calculation | Manual for loop | reduce |
| Report generation | Manual for loop | map + spread |
| Grade system | Not included | Added with ternary |
| Lines of code | 50+ lines | 20 lines |
| Style | Beginner JavaScript | Modern JavaScript |

## What It Does
- Calculates class average using reduce
- Sorts students from highest to lowest marks
- Generates full report with status and grade
- Above/Below Average status per student
- Grade A, B, or C based on marks

## What I Learned
The same logic that took 50+ lines and 5 separate 
functions in V1 — takes 20 lines in modern JavaScript.

reduce replaces manual total loops.
map replaces manual push loops.
spread operator replaces listing every property.
ternary replaces if/else blocks.

This refactor taught me that clean code is not 
about writing less — it's about understanding more.

## Technologies Used
- Pure JavaScript — No frameworks
- Modern ES6+ methods
