# Student Mark Filter & Average Calculator

A pure JavaScript project built from scratch 
to practice arrays, loops, functions and 
conditional logic.

## What it does
- Filters students who scored above 60
- Calculates the class average
- Identifies each student as above average 
  or below average

## Technologies Used
- Pure JavaScript (No frameworks)
- Runs directly in any browser console

## How to Run
No setup required. This is a pure JavaScript file - open it in any browser console or run it with Node.js :
node student-mark.js
