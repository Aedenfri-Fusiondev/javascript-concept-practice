# Student Mark Filter, Average & Report Generator

A pure JavaScript project built from scratch to practice arrays of objects, loops, functions, sorting, and conditional logic — no frameworks, no shortcuts.

---

## What It Does

- Filters students who scored above 60
- Calculates the class average
- Identifies each student as Above Average or Below Average
- Sorts students by marks from highest to lowest
- Generates a full student report combining all of the above

---

## Functions Breakdown

| Function | What It Does |
|---|---|
| `filter()` | Returns students who scored above 60 |
| `average()` | Calculates the class average marks |
| `knowAvg()` | Labels each student as Above or Below Average |
| `sorting()` | Sorts students by marks (highest first) |
| `getReport()` | Full report — sorted + marks + average status |

---

## Technologies Used

- Pure JavaScript (No frameworks)
- Runs directly in any browser console or Node.js

---

## How to Run

No setup required. Open it in any browser console or run it with Node.js:

```bash
node student-mark.js
```

## What I Learned

Building this taught me more than any tutorial. I started with just a simple filter function — but kept pushing further. Getting the `average()` to work took real effort, and then calling it *inside* another function (`getReport`) to generate a combined sorted report was a proper challenge.

The struggle with each function is where the real learning happened. By the end, I had 5 functions working together — and that felt like a real win.
