# User Profile Explorer

## V1 — Destructuring Practice

A mini JavaScript project built to demonstrate practical usage of **object destructuring**, **array destructuring**, **nested destructuring**, and the **rest operator** by generating a formatted user profile report.

---

## Project Highlights

| Feature | Implementation |
|---------|----------------|
| Object Destructuring | Extract nested user information |
| Array Destructuring | Retrieve skills and hobbies |
| Nested Destructuring | Access deeply nested objects |
| Rest Operator | Collect remaining properties |
| Template Literals | Generate formatted console output |

---

## What It Does

- Extracts user profile details using destructuring
- Retrieves address information from nested objects
- Extracts selected skills and hobbies from arrays
- Stores unextracted properties using the rest operator
- Generates a structured console report
