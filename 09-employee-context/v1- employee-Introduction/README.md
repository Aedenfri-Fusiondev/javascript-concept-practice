# 👤 Employee Introduction — V1

A pure JavaScript practice project built to understand `this` and control function context using `call()`, `apply()`, and `bind()`.

---

## 🎯 Purpose

Practice JavaScript function context by reusing a single `introduce()` method with different employee objects.

---

## 💻 Skills Demonstrated

- `this` keyword
- Object Methods
- `call()`
- `apply()`
- `bind()`
- Template Literals
- Object Properties

---

## ⚙️ How It Works

A reusable `introduce()` method generates employee introductions.

- **`call()`** — executes the function with a specific `this` value and individual arguments.
- **`apply()`** — executes the function with a specific `this` value and arguments as an array.
- **`bind()`** — creates a new function permanently bound to a specific `this` value.

---

## 🧠 What I Learned

I learned how JavaScript determines the value of `this` and how `call()`, `apply()`, and `bind()` can explicitly control a function's execution context.
